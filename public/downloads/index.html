Automatische Updates mit Obtainium

Obtainium fragt eine Adresse regelmäßig nach neuen Fassungen und installiert sie auf Wunsch. Für die Keksdose ist das diese Seite:

https://keksdose.netlify.app/downloads/

  1. In Obtainium unten auf Add App tippen und die Adresse oben einfügen.
  2. Obtainium erkennt die Seite als HTML-Quelle. In den Optionen Version Extract Whole Page einschalten und als Muster (\d+\.\d+\.\d+) eintragen.
  3. Speichern, in der Liste auf Install tippen – fertig. Neue Fassungen erscheinen dort von selbst.
